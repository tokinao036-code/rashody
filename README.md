# Мои расходы

Простой счётчик расходов. Работает без интернета и ставится на телефон как приложение.

## Что загружать на GitHub

```
index.html
sw.js
manifest.webmanifest
icons/  (icon.svg, icon-192.png, icon-512.png, apple-touch-icon.png)
```

Папку `.claude` загружать не нужно.

## Как выложить на GitHub Pages

1. На github.com создайте новый **публичный** репозиторий, например `rashody`.
2. Нажмите **Add file → Upload files** и перетащите туда файлы из списка выше (вместе с папкой `icons`). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите
   *Source: Deploy from a branch*, *Branch: main*, папка */ (root)*, нажмите **Save**.
4. Через 1–2 минуты сайт будет здесь: `https://ВАШ-ЛОГИН.github.io/rashody/`

## Как поставить на телефон маме

- **Android (Chrome):** откройте ссылку → меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает и без интернета.

> Важно: расходы хранятся **на самом телефоне**. На iPhone открывайте приложение всегда с одного и того же места
> (лучше со значка на экране «Домой») — у Safari и у значка отдельная память.
> Иногда делайте «Настройки → Сохранить копию», чтобы не потерять данные при смене телефона.

## Как обновить приложение после изменений

В файле `sw.js` поменяйте версию в первой строке (`rashody-v1` → `rashody-v2`) и загрузите файлы заново.
На телефоне обновление подтянется после одного-двух открытий.
